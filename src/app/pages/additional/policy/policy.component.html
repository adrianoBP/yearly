Google Services provide access to the following Google user data (referred as scopes):

User details

  • Publicly shared personal information
  • Primary email address

Calendar details

  • View and edit events across all Google Calendars associated with the account

4. Optional integrations

Some features can use third-party services with an API key that you create and add in Settings. All of them are optional, and the Application works without them.

  • Keys and request counts are stored in your browser and synced through a hidden app folder in your own Google Drive, so they work on all your devices. They are not sent to the Service Provider.
  • Requests go directly from your device to the service the key belongs to, and may include event details such as a location, a date or a flight number.
  • Each service handles that data under its own privacy policy: Google Gemini, TomTom, Ticketmaster, Aviationstack, FlightAware.
  • On Gemini's free tier, Google may use the requests you send to improve its products.
  • Anyone with access to your browser, or any script running in the Application, could read stored keys. Remove a key from Settings at any time.
